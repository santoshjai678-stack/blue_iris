1. OVERVIEW
--------------------------------------------------------------------------------
Integrated Yajra DataTables (`yajra/laravel-datatables-oracle` v12.7.2) across the
entire application to provide high-performance, server-side pagination, searching,
multi-column filtering, and sorting for large data scale without loading entire
database tables into PHP memory.

2. MODULES IMPLEMENTED WITH SERVER-SIDE YAJRA DATATABLES
--------------------------------------------------------------------------------

A. SALON EMPLOYEES DIRECTORY (/employees)
   - Controller: App\Http\Controllers\Tenant\EmployeeController@index
   - Blade View: resources/views/tenant/employees/index.blade.php
   - Server-side features:
     * Full Name + Initials avatar badge + Email column with link to employee profile.
     * Phone Number + Location city.
     * Assigned Store badge (links to salon) or "Unassigned" status.
     * Shift Start / End timings formatted as "09:00 AM - 06:00 PM".
     * Status Badges: Active (green), Inactive (red), Terminated (gray/rose).
     * Action buttons: View, Edit, Delete (with CSRF confirmation).
