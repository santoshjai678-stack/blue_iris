1. ISSUE IDENTIFIED:
--------------------
- User attempted to access tenant using path-based folder structure:
  http://quasar.localhost/blue_iris_latest_laravel/blue_iris_v2/
- In stancl/tenancy v3 with domain/subdomain tenancy:
  a) Tenants are routed by Host Domain (e.g. quasar.localhost), not folder paths.
  b) With 'php artisan serve' running on port 8000, the web root is already the 'public/' directory.
  c) When requests hit tenant domains with SESSION_DRIVER=database, the session handler queries the tenant database for the 'sessions' table.

-----------------------

B. Central Route Domain Isolation:
   - Updated routes/web.php to constrain central routes (SuperAdmin login, dashboard, tenant CRUD) to central domains (localhost, 127.0.0.1).
   - This ensures tenant subdomains (quasar.localhost:8000) are handled by routes/tenant.php without route collisions.
