1. OVERVIEW & PURPOSE
--------------------------------------------------------------------------------
Implemented a dedicated, secure Central SuperAdmin Authentication and Session
Protection system. All central management URLs (Dashboard, Tenant CRUD) are now
strictly guarded by the `superadmin` guard and session middleware. Unauthenticated
requests are automatically redirected to the SuperAdmin login portal.

- Columns: id, name, email (unique), phone_no, password (hashed), status (1=Active, 0=Inactive), remember_token, timestamps.

B. MODELS
---------
[CREATED] app/Models/Central/SuperAdmin.php
- Central SuperAdmin Eloquent model extending `Illuminate\Foundation\Auth\User`.
- Bound to central connection (`mysql`) and `super_admins` table.
- Implements password hashing casts and mass assignable fields.


C. CONFIGURATION
----------------
[MODIFIED] config/auth.php
- Added `superadmin` authentication guard:
    'guards' => [
        'web' => ['driver' => 'session', 'provider' => 'users'],
        'superadmin' => ['driver' => 'session', 'provider' => 'superadmins'],
    ]
- Added `superadmins` user provider:
    'providers' => [
        'users' => ['driver' => 'eloquent', 'model' => App\Models\User::class],
        'superadmins' => ['driver' => 'eloquent', 'model' => App\Models\Central\SuperAdmin::class],
    ]
- Added `superadmins` password broker configuration.


D. CONTROLLERS & LOGIC
----------------------
[CREATED] app/Http/Controllers/Superadmin/Auth/LoginController.php
- `showLoginForm()`: Renders superadmin login view or redirects to dashboard if already authenticated.
- `login(Request $request)`: Validates input, authenticates via `Auth::guard('superadmin')->attempt()`, checks active status (`status = 1`), regenerates session.
- `logout(Request $request)`: Logs out `superadmin` guard, invalidates session, regenerates CSRF token, redirects to `/superadmin/login`.


E. ROUTING & MIDDLEWARE
-----------------------
[MODIFIED] routes/web.php
- Root route `/`: Redirects to `/superadmin/dashboard` if logged in, otherwise `/superadmin/login`.
- Guest routes:
    - GET  /superadmin/login  -> LoginController@showLoginForm (Name: superadmin.login)
    - POST /superadmin/login  -> LoginController@login (Name: superadmin.login.post)
- Protected routes (Middleware: `auth:superadmin`):
    - POST /superadmin/logout -> LoginController@logout (Name: superadmin.logout)
    - GET  /superadmin/dashboard -> DashboardController@index (Name: superadmin.dashboard)
    - Resource /superadmin/tenants -> TenantController (Name: superadmin.tenants.*)

[MODIFIED] bootstrap/app.php
- Configured `$middleware->redirectGuestsTo(fn () => route('superadmin.login'));` to ensure unauthenticated users are automatically sent to the superadmin login page.


F. VIEWS (UI / UX)

- Features: Email & password fields, Remember Me checkbox, flash success/error messages, demo credential hints.

[MODIFIED] resources/views/layouts/superadmin.blade.php
